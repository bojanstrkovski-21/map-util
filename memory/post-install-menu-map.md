# Post-install menu map

`archboki-post-map-diagram/post-install-system-map.md` is the source notes for `03.arch-boki-post-install-gum.sh` and only the scripts that menu opens. Read it before extending the map. The script list at the bottom names every file `03` calls. There are 18. `install-scripts/130-archboki-install-apps.sh` does not call any further script. Audio and fonts are the other nested prompts.

The published page is generated by `archboki-post-map/gen_post_map.py`. It is not the Mermaid charts in the source notes. Those charts were separate `flowchart TD` diagrams: a rounded node for a menu, a square node for a script or command, Back / Main Menu / Quit left off, and package rows kept in tables. The HTML map uses menu, folder, and script glyphs, horizontal blocks, and Direct actions. Quit stays only on the Main Menu.

The ten source charts are Main Menu (four working choices), Update and Refresh, Choose Desktop, Core Utils, Install Apps (eight categories), then Text/office, Internet, Multimedia, Graphics, and System Tools. On the Core Utils chart, audio splits into PipeWire and PulseAudio. The font chart stops at Font Installation Manager and its three choices. The numbered font lists stay tables in the notes. The HTML map lists those packages on the rails.
