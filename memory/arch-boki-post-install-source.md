# Arch-Boki post-install source

The live entry point is `03.arch-boki-post-install-gum.sh` in [bojanstrkovski-21/arch-boki-post-install-dev](https://github.com/bojanstrkovski-21/arch-boki-post-install-dev) on `master`.

`01-arch_boki_bash.sh`, `02-arch_boki_bash_auto_choice.sh`, `04.arch-boki-rofi-post-install.sh`, and the Python GUI are earlier iterations. Leave them out unless asked.

Run `03` from the repo root. Every action uses a relative path: `./add-repos`, `./choose-desktop`, `./core-utils`, `./install-scripts`.

The install scripts are not in this repository. The written menu notes are `archboki-post-map-diagram/post-install-system-map.md`. The published map is `archboki-post-map/index.html`.
