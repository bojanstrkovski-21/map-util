Menu maps

Two maps of installer menus, kept in this repository. The Linutil map lists every tab, submenu, and action in Chris Titus Tech's Linutil. The Arch-Boki map lists every menu opened by the post-install gum script. How each map is built is on the Linutil about page and the Arch-Boki about page.
