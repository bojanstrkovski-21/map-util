    Menu title on screen: Install Core Utils and Drivers. Choices 3 and 7 open another prompt.

    Open a sub-tab for the menu, the audio prompt, or a font list.

    Menu · 8

    The eight install choices. Audio and Fonts open another prompt.

    • Cpu Check and Install Microcodecore-utils/microcode.shactionscriptNo menu. Reads lscpu Vendor ID. GenuineIntel installs intel-ucode. AuthenticAMD installs amd-ucode. Anything else prints the vendor and exits 1. The install command is pacman -Syu --noconfirm, so the system upgrades. The initramfs is not rebuilt.
    • Install GPU Driverscore-utils/gpu-drivers.shactionscriptNo menu. Looks at lspci for a VGA or 3D line that mentions nvidia or amd, and uses field 5 as the vendor. NVIDIA installs nvidia-dkms nvidia-utils nvidia-settings. AMD installs xf86-video-amdgpu. Anything else exits 1. Same pacman -Syu upgrade. No Intel path.
    • Install Audio Driverscore-utils/audio-drivers.shactionscriptRuns the script, then a 1/2 prompt. If jack2 is installed it is removed with pacman -Rdd before the prompt. -Rdd skips dependency checks.
    • Install Bluetooth Driversinstall-scripts/123-bluetooth.shactionscriptInstalls pacutils, then pacinstall --resolve-conflicts=all for bluez, bluez-libs, bluez-utils, blueman. Enables and starts bluetooth.service. Sets AutoEnable=true in /etc/bluetooth/main.conf.
    • Install Network Driversinstall-scripts/126-network.shactionscriptRemoves iptables with pacman -Rdd, then installs iptables-nft, networkmanager, networkmanager-openvpn, networkmanager-openconnect, network-manager-applet, nm-connection-editor, nftables, avahi, samba, NFS packages, the gvfs-* backends, nss-mdns, file-roller, webkit2gtk. Does not enable NetworkManager.
    • Install Printer Driversinstall-scripts/124-printers.shactionscriptInstalls pacutils, then pacinstall for cups, cups-pdf, cups-browsed, cups-filters, bluez-cups, ghostscript, gsfonts, gutenprint, foomatic-db-gutenprint-ppds, libcups, system-config-printer. Enables and starts cups.service.
    • Install Fontsinstall-scripts/125-installfont-new.shmenuscriptReplaces the gum screen with Font Installation Manager. Leaving that script returns to this Core Utils menu. It does not stack another 03.
    • Install Core Utilsinstall-scripts/118-core.shactionscriptNo menu. One pacman -S --needed --noconfirm of base, base-devel, linux-headers, dkms, git, cmake, devtools, archiso and ISO tools, fwupd, fzf, ripgrep, plocate, flatpak, yad, zenity, xdg-utils, udisks2, and archive tools (p7zip, unrar, unzip, unace).

    How this map follows the post-install script.

    How a choice moves

    Before the first menu, the script runs sudo pacman -S gum --needed --noconfirm, clears the screen, and prints the ARCH BOKI banner. Then it loops the Main Menu. Run it from the repo root. Every action uses a path like ./add-repos/....

    1. Menu. Clears the screen and opens the next menu. It stays on that menu.
    2. Action. Runs a script or a pacman / yay command, waits for Enter, then shows the same menu again. Apps rows are the exception: there is no Enter pause, and the same submenu stays open.
    3. 4. Install Apps runs install-scripts/130-archboki-install-apps.sh and then exits 03 with that script's status. You do not return to the Main Menu from it.
    4. 5. Quit is only on the Main Menu. It runs exit 0. Back and Main Menu are not listed on the other menus.

    Only three places open a further menu: the four Main Menu branches, the audio prompt, the font manager, and the apps script. 01, 02, 04, and the Python GUI are earlier tries and are not in this map.

    Chips

    action
    Runs a script or command, then shows this menu again
    menu
    Clears the screen and opens the next menu
    pick
    Pick list: numbers, a or all, b back, q quit
    nested
    Starts another copy of a script on top of this menu
    exit
    Runs exit and ends that process
    return
    Leaves this script and returns to the menu under it
    pacman
    sudo pacman -S --needed --noconfirm, unless the detail says otherwise
    yay
    Installed with yay
    script
    A separate script on the path
    inline
    A command inside 03, not its own script
